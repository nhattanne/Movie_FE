# 🎬 DevChill

**DevChill** is an online platform for streaming movies and series, supporting HD/4K viewing, ticket management, Premium subscription plans, and AI-powered movie recommendations tailored to user preferences.

The project is built with **React** for the frontend and **Node.js + Express** for the backend, optimized for user experience and efficient data management.

---

## 🚀 Technologies Used

### 🎨 Frontend
- **React.js** — Dynamic UI, component-driven development  
- **Tailwind CSS** — Modern and responsive design  
- **Framer Motion** — Smooth animations  
- **React Router v6** — SPA routing  
- **React-Icons** — Flexible and beautiful icons  
- **React QR Code** — Display QR codes for tickets and payments  
- **Axios / Fetch API** — Communicate with backend  
- **React Toastify** — Toast notifications  

---

### 🛠 Backend
- **Node.js + Express.js** — RESTful API  
- **Sequelize + PostgreSQL/MySQL** — Database management  
- **JWT** — Authentication & authorization  
- **bcrypt** — Password hashing  
- **Stripe** — Premium subscription payments  
- **CORS & Helmet** — API security  

---

### 🤖 AI Features
- **Personalized movie recommendations** based on watch history  
- **Chatbot** for movie suggestions and Premium information
